# Archive

Open [`index.html`](index.html) for the maintained archive catalog. It links
directly to every retired HTML prototype and to the active Arcana research tool
under [`../tools/`](../tools/).

The archive is reference-only. Some pages depend on historical `src/` APIs or
external CDN modules and are intentionally preserved without being restored to
the supported launcher surfaces.

## Categories

- `combat-labs/` — retired weapon, punch, fencer, and combat-director experiments.
- `enemy-labs/` — retired enemy viewers, rigs, and bestiary experiments.
- `legacy-games/` — the original top-down shooter prototype.
- `visual-experiments/` — maze and rendering diagnostics.
- `wizard-of-legend/` — preserved source-first Arcana notes.
