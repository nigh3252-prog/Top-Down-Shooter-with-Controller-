# Reference / donor files

This folder is reserved for old one-file prototypes and donor implementations as the Stone Wanderer game becomes the main trunk.

Nothing was moved here yet in the first weapons-module pass because the priority was to keep the current launcher links stable while extracting the first live source seam. The next cleanup pass can copy or move the old pages here once their links are updated deliberately.

Likely future reference files:

- `top-down-shooter.html` — donor for controller input, enemies, HUD, damage, death/respawn, and card tray behavior.
- `stone-wanderer-stance-chain-lab-core.html` — old all-in-one Stone Wanderer core once the real game shell replaces it.
- `stone-wanderer-individual-move-test.html` — donor/reference for move rating UI.
- `sound-foundry-retro-beasts.html` — donor/reference for procedural audio recipes.
